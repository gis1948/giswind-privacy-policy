Account & Data Deletion

How to delete your Gis account data and locally stored data in the GisWind Windows application, and exactly what is removed or retained.

Applies to: GisWind (GISIptv Windows). · Contact: gis1948@gmail.com

Delete your Gis account (cloud data)

If you signed in to GisWind with a Gis account, you can delete the account from inside the app:

  1. Open Settings.
  2. In the Cloud Sync section, select Delete cloud account….
  3. Confirm the warning. The server-side account record, registered devices, and any server-side sync data associated with the account are then removed from the configured sync server.

Requires being signed in to a Gis account with sync configured. If you are not signed in, there is no server-side account to delete.

How the deletion works (server-first)

Deletion is server-first. Only if the sync server confirms the deletion does the app then clear your local account material. If the server deletion fails, the app reports an error and does not clear your local account or claim success.

Removed on the server: the account record, its escrow (username, password verifier), registered device entries, and any sync payloads actually stored for the account. The current GisWind application build does not currently demonstrate active application-level enqueue/apply synchronization of favorites, settings, or other library changes; the generic sync infrastructure should not be read as evidence that such payloads are currently being produced by the app.

Cleared on your device (after the server confirms):

  • Stored username and password verifier/salt (the account record), and the end-to-end sync key (kSync).
  • The signed-in state, remembered-account state, account identifier, and active account-database reference are cleared, along with the device's ownership/agreement state, returning the app to its signed-out welcome flow.

What is retained after deleting your account

Deleting your Gis account does not erase the following, which stay on your PC and can be removed separately. The local library database file is retained; only the active account identity/reference is cleared.

  • Device identity: device ID, machine/device name, and the Ed25519 device key pair.
  • Local library database: playlists (including provider credentials you entered), channel lists, favorites, EPG data, recordings, viewing history, search history, and settings.
  • Prefill username: the last username, kept only to prefill the login form.
  • Diagnostics and the anonymous analytics ID: error.log, startup.log, and .client_id.

To remove all local data, close the app and delete the %LocalAppData%\GISIptvWindows folder, or uninstall the app. Local deletion is immediate and controlled entirely by you.

If something fails

  • Server deletion fails (for example a network error): nothing is deleted and no local data is cleared. You can retry from the same Settings screen. The app shows the error message it received.
  • Local cleanup fails after the server confirmed deletion: the server-side account is already permanently deleted; the app warns that the local sign-out did not finish and lets you retry, so you are not left with stale signed-in credentials.

Recovery

A Gis account can normally be restored on another device using the 12-word recovery phrase generated when the account was created. However, once the account has been deleted from the server, there is no server account left to restore and the recovery phrase no longer restores it. Because server deletion is permanent, keep your recovery phrase only if you intend to keep the account; if you delete the account, destroy the phrase.

No account? No problem

If you never created a Gis account, GisWind stores everything only on your PC. There is no server-side data associated with you, and you can remove all app data by deleting the %LocalAppData%\GISIptvWindows folder or uninstalling the app.
